# Undercity Initiative Tracker

## Sobre o Projeto

O Undercity Initiative Tracker é uma aplicação web desenvolvida para auxiliar jogadores de Magic: The Gathering no acompanhamento da dungeon **Undercity**, utilizada pela mecânica de **Iniciativa**.

A aplicação permite selecionar jogadores, movimentar seus respectivos tokens entre as salas da Undercity e reiniciar o estado do tabuleiro quando necessário.

link: https://balokbk.github.io/Undercity-token/

---

## Funcionalidades

### Mapa Interativo da Undercity

- Representação visual completa da dungeon Undercity.
- Áreas interativas posicionadas sobre o mapa oficial.
- Interface adaptada para diferentes tamanhos de tela.

### Controle de Jogadores

- Suporte para até quatro jogadores simultaneamente.
- Seleção visual do jogador ativo.
- Cada jogador possui um token próprio e identificável.
